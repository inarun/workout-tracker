The web app has closed

The Ledger web app closed on 16 November 2026. Ledger continues as Lifting Ledger for iPhone and Apple Watch.

If you used an account, your log is still in it: sign in to the same account in the iPhone app.

A log that was saved only in your browser is still stored in that browser, but it can no longer be opened here. If you need it, email support@nusayb.me.
